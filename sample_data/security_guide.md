# 信息安全事件响应指南

## 账号异常

发现账号疑似被盗后，员工应立即修改密码并在安全中心注销所有已登录设备，同时联系安全值班人员。值班人员应冻结可疑会话、保存登录日志，并检查最近二十四小时内的敏感操作。不得通过普通聊天工具发送密码或验证码。

## 数据泄露

发现数据可能外泄时，不得自行删除现场文件或日志。应在十分钟内通过安全热线报告，记录发现时间、影响系统和数据类型。安全负责人负责确定事件等级，并协调法务、运维和业务团队。对外披露必须经过法务和公司授权代表批准。

## 恶意邮件

收到可疑附件时不要打开，也不要转发给同事确认。应使用邮件客户端的“报告钓鱼”功能提交样本。若已经点击链接，应立即断开网络并联系安全值班人员，不要继续在该设备上输入账号信息。
