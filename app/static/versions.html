案例：流式响应读取了已经关闭的资源

路由返回后，流式生成器仍需要读取依赖提供的资源。依赖何时清理，会决定这段代码是否失败。实验同时对照“借用依赖资源”与“流式生成器自行管理资源”，并检查后台任务中的同类问题。

案例使用有开关状态的模拟资源，直接调用真实 FastAPI 的 ASGI 链路。它检查资源生命周期，不连接数据库，也不执行输入的代码。

查看最小流式复现的核心代码
async def dependency():
    resource = Resource()
    try:
        yield resource
    finally:
        resource.close()

@app.get("/")
async def route(resource=Depends(dependency)):
    async def generate():
        yield resource.read()  # 清理后读取会报错
    return StreamingResponse(generate())
